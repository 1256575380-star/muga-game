# MUGA · 曼联复兴办公室

v0.6，真实球员名单与黑色幽默经营事件的免费网页小游戏。原生 HTML/CSS/JavaScript，无外部运行依赖，无需玩家登录。

- 2026-11-14 快照：105 家俱乐部、3,140 名真实球员。身份资料来自 ESPN 公开阵容，曼联名单与英超官方核对；各球员详情有来源链接。
- 能力、潜力、工资、合同、伤病及经营剧情为游戏模拟，不代表真实人物经历。独立球迷作品。
- 前五季只使用真实球员，第六季起每个转会窗加入四名明确标记的虚构年轻小将。
- 三个本地存档，自动续玩、导入导出和跨赛季交接。旧版任期保留原阵容，真实名单请在空存档中新建任期。

## 游玩与部署

本仓库根目录即发布目录。Render 选择 Static Site，分支 `main`，Build Command 为 `echo Static MUGA assets ready`，Publish Directory 为 `.`。也可使用 `render.yaml`。不需要数据库、账户密钥或付费服务器。

`muga-offline.html` 是完整离线单文件。下载后用支持网页脚本的浏览器打开，或部署整个目录到任意静态托管服务。更换网址时请先导出存档。

大陆网络可达性取决于托管域名和运营商，需用实际网络验证；离线版运行时不访问外部服务。

## 源码和测试

根目录 JS/CSS 为未压缩游戏源码。`muga-source-v0.6.zip` 含完整开发项目、65 项测试、资料审校记录及离线生成脚本。解压后运行 `node --test tests/*.test.cjs`。

自动测试 65 项通过；390×844 手机浏览器验证真实名单、详情、市场和刷新续玩。
